# SWYNEX – Exploratory Data Analysis

## Project overview
This project performs exploratory data analysis on the cleaned retail store sales dataset from Task 1 using Python, pandas, and Matplotlib.

## Project files
- `SWYNEX-cleaned-retail-sales.csv` – cleaned input dataset from Task 1
- `eda_analysis.py` – reproducible analysis script
- `EDA-REPORT.md` – descriptive statistics, findings, and limitations
- `charts/` – four charts generated by the analysis script

## Run the analysis
Install the required libraries:
```bash
pip install pandas matplotlib
```
Keep the CSV and Python script in the same folder, then run:
```bash
python eda_analysis.py
```
The script creates the `charts` folder and `EDA-REPORT.md`.

## Analysis approach
Sales totals and averages use rows with a recorded `Total Spent`. Missing `Quantity` and `Total Spent` values are not guessed or filled during EDA. The report notes that 2025 contains partial-year data and should not be compared directly with complete calendar years.

## Scope and limitations
The analysis also flags potential high-value transactions using the 1.5×IQR rule for review; flagged values are not automatically removed. The dataset contains sales amounts but no cost information, so this analysis discusses recorded sales rather than profit. Findings are descriptive and do not establish causes.
